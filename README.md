# Kitchen Manager Simulator

A Python-based kitchen stock management simulator.

The player takes the role of a kitchen stock manager responsible for managing inventory, deliveries, preparation lists and bookings.

## Planned Features

- Inventory management
- Fast food menu
- Recipe-based ingredient consumption
- Low stock warnings
- Deliveries
- Suppliers
- Prep lists
- Bookings
- Stock forecasting
- Food waste management
